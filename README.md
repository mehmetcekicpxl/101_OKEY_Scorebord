# 101 Okey Scorebord

Een handige mobiele applicatie om de scores bij te houden tijdens het spelen van het populaire spel 101 Okey.

## Functionaliteiten
* Eenvoudig scores toevoegen en berekenen.
* Gebruiksvriendelijke interface.
* Ontwikkeld voor Android.

## Installatie
Open dit project in Android Studio, synchroniseer Gradle en installeer de applicatie op een emulator of een fysiek apparaat.
